Урок 1: Знакомство с Python

Основы языка программирования Python: переменные, функция print() и настройка среды разработки

Что такое Python?

Python — это высокоуровневый язык программирования общего назначения, который отличается простым синтаксисом и читаемостью кода. Он был создан Гвидо ван Россумом и впервые выпущен в 1991 году.


Основные особенности Python:

  • Интерпретируемый язык (не требует компиляции)
  • Динамическая типизация
  • Автоматическое управление памятью
  • Большое количество библиотек и фреймворков
  • Поддержка различных парадигм программирования

Первая программа

Традиционно первая программа на любом языке программирования выводит на экран фразу "Hello, World!". В Python это делается с помощью функции print():

print("Hello, World!")

Функция print() выводит на экран то, что указано в скобках. Это может быть текст (строка), число или значение переменной.

Переменные в Python

Переменная — это именованная область памяти, в которой хранятся данные. В Python переменные создаются в момент присваивания им значения. В Python не нужно явно указывать тип переменной — интерпретатор определяет его автоматически на основе присвоенного значения.

# Создание переменных
name = "Анна" # Строковая переменная
age = 25 # Целочисленная переменная
height = 1.68 # Вещественная переменная
is_student = True # Логическая переменная

# Вывод значений переменных
print(name)
print(age)
print("Имя:", name, "Возраст:", age)

Урок 2: Ввод данных и арифметические операции

Работа с пользовательским вводом, основные математические операции и типы данных в Python

Функция input() - ввод данных

Функция input() позволяет получать данные от пользователя во время выполнения программы. Она приостанавливает выполнение программы и ждет, пока пользователь введет текст с клавиатуры и нажмет Enter.

# Простейший пример использования input()
name = input("Введите ваше имя: ")
print("Привет,", name, "!")

Все, что вводит пользователь, всегда возвращается как строка (string). Это важно помнить при работе с числами.

Арифметические операции

Python поддерживает все основные арифметические операции:

# Основные арифметические операции
a = 10
b = 3

# Сложение
sum_result = a + b # 13

# Вычитание

# Умножение
mult_result = a * b # 30

# Деление
div_result = a / b # 3.333...

# Целочисленное деление
int_div_result = a // b # 3

# Остаток от деления
mod_result = a % b # 1

# Возведение в степень
pow_result = a ** b # 1000

Урок 3: Условные операторы if-else

Принятие решений в программах с помощью условных операторов if, elif, else

Условный оператор if

Оператор if позволяет выполнять код только при выполнении определенного условия. Это основа для создания "умных" программ, которые могут принимать решения.

# Простейший пример if
age = 18

if age >= 18:
    print("Вы совершеннолетний!")
    print("Можете голосовать на выборах")

Все, что находится после двоеточия и с отступом (обычно 4 пробела) будет выполнено только если условие истинно.

Операторы сравнения

Для создания условий используются операторы сравнения:

# Операторы сравнения
# == равно
# != не равно
# > больше
# < меньше
# >= больше или равно
# <= меньше или равно

x = 10
y = 5

if x > y:
    print("x больше y")

if x == 10:
    print("x равно 10")

Урок 4: Циклы while и for

Автоматизация повторяющихся действий с помощью циклов

Цикл while

Цикл while повторяет блок кода, пока условие истинно. Это полезно, когда мы не знаем заранее, сколько раз нужно повторить действие.

# Простейший пример while
counter = 1

while counter <= 5:
    print(f"Счетчик: {counter}")
    counter += 1 # Увеличиваем счетчик на 1

print("Цикл завершен!")

Цикл for

Цикл for используется для повторения блока кода определенное количество раз или для перебора элементов последовательности.

# Цикл for с функцией range()
for i in range(5):
    print(f"Итерация номер: {i}")

# range() с параметрами
for i in range(1, 6): # от 1 до 5
    print(f"Число: {i}")

# range() с шагом
for i in range(0, 10, 2): # четные числа от 0 до 8
    print(f"Четное: {i}")

Урок 5: Списки и строки

Работа с коллекциями данных: списками и строками в Python

Списки (lists)

Список — это упорядоченная коллекция элементов, которая может содержать данные разных типов. Списки изменяемы (мутабельны).

# Создание списков
numbers = [1, 2, 3, 4, 5]
fruits = ["яблоко", "банан", "апельсин"]
mixed = [1, "текст", 3.14, True]

# Обращение к элементам
print(fruits[0]) # "яблоко" (первый элемент)
print(fruits[1]) # "банан"
print(fruits[-1]) # "апельсин" (последний элемент)

Строки (strings)

Строка — это последовательность символов. Строки в Python неизменяемы (иммутабельны).

# Работа со строками
text = "Hello, World!"

# Индексация строк
print(text[0]) # "H"
print(text[7]) # "W"
print(text[0:5]) # "Hello" (срез)

# Методы строк
print(text.upper()) # "HELLO, WORLD!"
print(text.lower()) # "hello, world!"
print(text.replace("World", "Python"))
print(text.split(", ")) # ['Hello', 'World!']

Урок 6: Функции и модули

Создание повторно используемого кода с помощью функций и работа с модулями

Создание функций

Функция — это блок кода, который выполняет определенную задачу и может быть вызван многократно. Функции помогают организовать код и избежать повторений.

# Простая функция без параметров
def greet():
    print("Привет, мир!")
    print("Добро пожаловать в Python!")

# Вызов функции
greet()

# Функция с параметрами
def greet_person(name):
    print(f"Привет, {name}!")

greet_person("Анна")
greet_person("Иван")

Возврат значений

Функции могут возвращать значения с помощью оператора return. Это позволяет использовать результат функции в других частях программы.

# Функция, возвращающая значение
def add_numbers(a, b):
    result = a + b
    return result

# Использование возвращаемого значения
sum_result = add_numbers(5, 3)
print(f"Сумма: {sum_result}")

# Можно использовать прямо в выражении
total = add_numbers(10, 20) * 2
print(f"Удвоенная сумма: {total}")

Словари (Dictionary) в Python

Словарь (dict) — это неупорядоченная коллекция пар "ключ-значение". Ключи должны быть уникальными и неизменяемыми объектами (строки, числа, кортежи). Словари оптимизированы для быстрого доступа к значениям по ключу.

# Создание словаря
student = {
    "name": "Анна",
    "age": 20,
    "course": "Информатика",
    "grades": [4, 5, 4, 5]
}

# Доступ к значениям
print(student["name"]) # Анна
print(student.get("age")) # 20

# Изменение значений
student["age"] = 21
student["city"] = "Москва" # Добавление новой пары

Важная особенность

Словари не гарантируют порядок элементов (до Python 3.7). Для упорядоченных словарей можно использовать collections.OrderedDict или обновлять Python до версии 3.7+, где порядок сохраняется.

Методы словарей

Словари имеют множество полезных методов для работы с данными:

# Основные методы словарей
capitals = {
    "Россия": "Москва",
    "Франция": "Париж",
    "Германия": "Берлин"
}

# keys() - возвращает ключи
countries = capitals.keys()
print("Страны:", list(countries))

# values() - возвращает значения
cities = capitals.values()
print("Столицы:", list(cities))

# items() - возвращает пары ключ-значение
for country, capital in capitals.items():
    print(f"Столица {country} - {capital}")

# pop() - удаляет элемент по ключу
removed = capitals.pop("Франция")
print(f"Удалена столица: {removed}")

Множества (Set)

Множество (set) — это неупорядоченная коллекция уникальных элементов. Множества поддерживают математические операции: объединение, пересечение, разность.

# Создание множеств
numbers = {1, 2, 3, 4, 5}
colors = set(["красный", "синий", "зеленый"])

# Добавление элементов
numbers.add(6)
colors.add("желтый")

# Удаление элементов
numbers.remove(3)
colors.discard("синий") # Не вызывает ошибку, если элемента нет

# Операции с множествами
A = {1, 2, 3, 4}
B = {3, 4, 5, 6}

print("Объединение:", A | B) # {1, 2, 3, 4, 5, 6}
print("Пересечение:", A & B) # {3, 4}
print("Разность:", A - B) # {1, 2}
print("Симметричная разность:", A ^ B) # {1, 2, 5, 6}

Важно знать!

Множества не поддерживают индексацию и срезы, так как они неупорядочены. Элементы множества должны быть хешируемыми (неизменяемыми) типами данных.

Урок 8: Работа с файлами

Чтение и запись данных в файлы, обработка исключений при работе с файловой системой

Открытие и закрытие файлов

Python предоставляет встроенные функции для работы с файлами. Основная функция open() открывает файл и возвращает файловый объект.

# Открытие файла для чтения
file = open("example.txt", "r")
content = file.read()
file.close()

# Лучший способ: использование контекстного менеджера
with open("example.txt", "r") as file:
    content = file.read()
# Файл автоматически закрывается

Режимы открытия файлов

  • "r" - чтение (по умолчанию)
  • "w" - запись (перезаписывает файл)
  • "a" - добавление в конец файла
  • "x" - создание нового файла
  • "b" - бинарный режим (например, "rb", "wb")
  • "t" - текстовый режим (по умолчанию)
  • "+" - чтение и запись ("r+", "w+")

Чтение из файлов

Существует несколько методов для чтения данных из файла, каждый из которых полезен в разных ситуациях:

with open("data.txt", "r", encoding="utf-8") as file:
    # read() - чтение всего файла
    all_content = file.read()
    
    # readline() - чтение одной строки
    file.seek(0) # Возвращаемся в начало файла
    first_line = file.readline()
    
    # readlines() - чтение всех строк в список
    file.seek(0)
    all_lines = file.readlines()
    
    # Итерация по файлу построчно
    file.seek(0)
    for line in file:
        print(line.strip()) # strip() удаляет символы перевода строки

Запись в файлы

Для записи данных в файл используются методы write() и writelines(). Важно помнить о режимах открытия файла и кодировке.

# Запись текста в файл
with open("output.txt", "w", encoding="utf-8") as file:
    file.write("Первая строка\n")
    file.write("Вторая строка\n")
    file.write("Третья строка\n")

# Запись списка строк
lines = ["Яблоко\n", "Банан\n", "Апельсин\n"]

with open("fruits.txt", "w") as file:
    file.writelines(lines)

# Добавление в конец файла
with open("log.txt", "a") as file:
    import datetime
    timestamp = datetime.datetime.now()
    file.write(f"Запись добавлена: {timestamp}\n")

Важно!

При использовании режима "w" существующий файл будет полностью перезаписан. Для добавления данных используйте режим "a". Всегда указывайте кодировку (encoding="utf-8") для корректной работы с русским текстом.

Урок 9: Обработка исключений

Обработка ошибок в программах с помощью конструкций try-except-finally, создание пользовательских исключений

Базовые исключения

Исключения (exceptions) — это специальные объекты, которые возникают при ошибках во время выполнения программы. Python предоставляет встроенные типы исключений для различных ситуаций.

# Примеры распространенных исключений

# ZeroDivisionError - деление на ноль
# result = 10 / 0

# TypeError - несовместимые типы
# result = "строка" + 123

# ValueError - неверное значение
# number = int("не число")

# IndexError - индекс за пределами списка
# items = [1, 2, 3]
# item = items[10]

# KeyError - ключ не найден в словаре
# d = {"a": 1}
# value = d["b"]

# FileNotFoundError - файл не найден
# file = open("несуществующий_файл.txt", "r")

# AttributeError - атрибут не найден
# x = 10
# x.append(5)

Иерархия исключений

Все исключения наследуются от базового класса BaseException. Основные типы: Exception (все обычные исключения), ArithmeticError (математические ошибки), LookupError (ошибки поиска), OSError (ошибки операционной системы).

Конструкция try-except

Для обработки исключений используется конструкция try-except. Код в блоке try выполняется, и если возникает исключение, выполнение переходит в блок except.

# Базовая обработка исключений
try:
    number = int(input("Введите число: "))
    result = 100 / number
    print(f"Результат: {result}")
except ValueError:
    print("Ошибка: введено не число!")
except ZeroDivisionError:
    print("Ошибка: деление на ноль!")
except Exception as e:
    print(f"Неизвестная ошибка: {e}")
else:
    print("Операция выполнена успешно!")
finally:
    print("Блок finally выполняется всегда")

Блоки else и finally

else выполняется только если в блоке try не возникло исключений. finally выполняется всегда, независимо от того, было исключение или нет. Это идеальное место для освобождения ресурсов (закрытие файлов, соединений с БД).

Создание пользовательских исключений

Вы можете создавать собственные типы исключений для обработки специфических ошибок в вашем приложении. Пользовательские исключения должны наследоваться от класса Exception.

# Создание пользовательских исключений
class InvalidAgeError(Exception):
    def __init__(self, age, message="Недопустимый возраст"):
        self.age = age
        self.message = message
        super().__init__(self.message)
    
    def __str__(self):
        return f"{self.message}: {self.age}"

# Использование пользовательского исключения
def register_user(name, age):
    if age < 0 or age > 120:
        raise InvalidAgeError(age)
    elif age < 18:
        raise InvalidAgeError(age, "Возраст меньше 18 лет")
    else:
        print(f"Пользователь {name} успешно зарегистрирован")

# Обработка пользовательского исключения
try:
    register_user("Анна", 25)
    register_user("Иван", 16)
except InvalidAgeError as e:
    print(f"Ошибка регистрации: {e}")

Урок 10: Объектно-ориентированное программирование

Основы ООП: классы, объекты, наследование, инкапсуляция и полиморфизм в Python

Классы и объекты

Класс — это шаблон для создания объектов. Объект — это экземпляр класса. Классы объединяют данные (атрибуты) и методы (функции) для работы с этими данными.

# Создание простого класса
class Person:
    # Конструктор класса (инициализатор)
    def __init__(self, name, age):
        self.name = name # Атрибут экземпляра
        self.age = age
    
    # Метод экземпляра
    def introduce(self):
        return f"Привет, меня зовут {self.name} и мне {self.age} лет"
    
    # Еще один метод
    def have_birthday(self):
        self.age += 1
        print(f"С днем рождения! Теперь тебе {self.age} лет")

# Создание объектов (экземпляров класса)
person1 = Person("Анна", 25)
person2 = Person("Иван", 30)

# Использование методов
print(person1.introduce())
print(person2.introduce())

person1.have_birthday()
print(person1.introduce())

Параметр self

Параметр self — это ссылка на текущий экземпляр класса. Он всегда должен быть первым параметром методов экземпляра, но при вызове метода Python передает его автоматически.

Наследование

Наследование позволяет создавать новые классы на основе существующих, расширяя или изменяя их функциональность. Дочерний класс наследует атрибуты и методы родительского класса.

# Базовый (родительский) класс
class Animal:
    def __init__(self, name, species):
        self.name = name
        self.species = species
    
    def make_sound(self):
        print("Животное издает звук")
    
    def get_info(self):
        return f"{self.name} ({self.species})"

# Дочерний класс (наследует от Animal)
class Dog(Animal):
    def __init__(self, name, breed):
        # Вызов конструктора родительского класса
        super().__init__(name, "Собака")
        self.breed = breed # Новый атрибут
    
    # Переопределение метода
    def make_sound(self):
        print("Гав! Гав!")
    
    # Новый метод
    def fetch(self):
        print(f"{self.name} принес палку!")

# Еще один дочерний класс
class Cat(Animal):
    def __init__(self, name, color):
        super().__init__(name, "Кот")
        self.color = color
    
    def make_sound(self):
        print("Мяу!")
    
    def sleep(self):
        print(f"{self.name} сладко спит")

# Использование классов
dog = Dog("Бобик", "Овчарка")

Инкапсуляция и свойства

Инкапсуляция — это механизм сокрытия внутренней реализации объекта. В Python для этого используются приватные атрибуты (с префиксом __) и свойства (@property).

# Класс с инкапсуляцией
class BankAccount:
    def __init__(self, owner, initial_balance=0):
        self.owner = owner
        self.__balance = initial_balance # Приватный атрибут
        self.__transaction_history = []
    
    # Геттер (получение значения)
    @property
    def balance(self):
        return self.__balance
    
    # Сеттер (установка значения с проверкой)
    @balance.setter
    def balance(self, value):
        if value < 0:
            raise ValueError("Баланс не может быть отрицательным")
        self.__balance = value
    
    # Метод для депозита
    def deposit(self, amount):
        if amount <= 0:
            raise ValueError("Сумма депозита должна быть положительной")
        self.__balance += amount
        self.__transaction_history.append(f"Депозит: +{amount}")
        print(f"Внесено {amount}. Новый баланс: {self.__balance}")
    
    # Метод для снятия
    def withdraw(self, amount):
        if amount <= 0:
            raise ValueError("Сумма снятия должна быть положительной")
        if amount > self.__balance:
            raise ValueError("Недостаточно средств на счете")
        self.__balance -= amount
        self.__transaction_history.append(f"Снятие: -{amount}")
        print(f"Снято {amount}. Новый баланс: {self.__balance}")

            sys.exit()

    keys = pygame.key.get_pressed()
